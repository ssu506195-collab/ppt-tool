讓 AI 新增一篇文章

下載完整專案後，在 AI 編碼工具中開啟資料夾，先讓它閱讀根目錄的 AGENTS.md，再提出具體內容需求。例如：

請先閱讀 AGENTS.md 與 content/schema.md，新增一篇「模態分析的網格檢查」觀念筆記。以 Workbench 2024 R2 為準，英文選項附中文名稱，引用官方文件；未執行的網格比較必須標記為待驗證。完成後執行生成與檢查，更新變更紀錄。

新增流程

  1. 填寫文章模板

    複製 templates/article.json 到 content/articles/，使用英文小寫連字號檔名，依 content/schema.md 填妥欄位。

  2. 重新生成網站

    執行 python scripts/build.py。首頁、分類頁、文章頁與搜尋用資料會同步更新；不需要手動製作每一頁的導覽。

  3. 檢查與交接

    執行 python scripts/check.py，再檢查桌面與手機頁面。來源與 docs/ 一起提交 GitHub，並更新 CHANGELOG.md。

什麼可以寫成「已驗證」？

閱讀官方文件，代表文件查證；完成 ANSYS 操作並留下版本、操作者、日期與實際結果證據，才可標示實機驗證。網站檢查成功與模擬結果正確，是兩種不同的檢查。

延伸到其他軟體

先在 content/modules.json 宣告新分類，再新增對應文章。沿用相同欄位與視覺規則，同時交代各軟體特有的假設、操作環境與結果檢查方式。
